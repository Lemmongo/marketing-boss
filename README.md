# Marketing Boss

Аналізатор конкурентів у соцмережах на реальних API. Один HTML-файл, без збірки й сервера.

**Демо:** https://ТВІЙ-НІК.github.io/marketing-boss/

## Що вміє

- Аналіз ніші за хештегом: реальні перегляди, лайки, коментарі, ER з YouTube Data API v3 та RapidAPI
- 12 метрик з перемикачами видимості: швидкість, медіана, comment rate, концентрація топ-10%, частота публікацій
- Теплова карта «коли постять лідери» за реальними датами публікацій
- Слова-переможці в заголовках топ-контенту
- AI-пошук реальних конкурентів у ніші з описами (Claude або GPT)
- Генератор крео-ідей: відео, статика, хуки, A/B тести — по 15 на сторінку з догенерацією
- AI-аналітик у чаті з повним контекстом виміряних даних
- Дві мови (UA/EN), дві валюти (₴/$), експорт CSV

Жодних згенерованих цифр: якщо джерело не підключене — показується прочерк, а не вигадане число.

## Ключі

Ключі вводяться кожним користувачем окремо в розділі **«API ключі»** і зберігаються **лише в його браузері** (localStorage). Вони нікуди не передаються, окрім самих API, і не потрапляють у цей репозиторій.

| Ключ | Обовʼязковий | Де взяти | Ціна |
|---|---|---|---|
| Anthropic (Claude) | так, для AI-функцій | console.anthropic.com/settings/keys | від $5 поповнення |
| YouTube Data API v3 | для реальних метрик | console.cloud.google.com → APIs → YouTube Data API v3 | безкоштовно |
| RapidAPI | опційно, Instagram/TikTok | rapidapi.com → Instagram/TikTok Scraper | ~$10/міс |
| OpenAI | альтернатива Claude | platform.openai.com/api-keys | оплата за токени |

### Обмеж свій YouTube-ключ

Google Cloud Console → Credentials → твій ключ → **Application restrictions: Websites** → додай `https://ТВІЙ-НІК.github.io/*`. Інакше ключ зможе використати будь-хто, хто його побачить.

## Локальний запуск

Просто відкрий `index.html` у браузері. Нічого встановлювати не треба.
